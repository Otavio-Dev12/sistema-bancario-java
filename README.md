\# 🏦 Sistema Bancário em Java



Sistema bancário desenvolvido em Java com o objetivo de praticar Programação Orientada a Objetos e conceitos fundamentais da linguagem.



\## 📚 Conceitos utilizados



\- Classes e objetos

\- Encapsulamento

\- Herança

\- Polimorfismo

\- Classe abstrata

\- Interfaces

\- ArrayList

\- Métodos

\- Construtores

\- Sobrescrita de métodos (`@Override`)



\## 💰 Funcionalidades



\- Criação de contas

\- Conta corrente

\- Conta poupança

\- Depósito

\- Saque

\- Cálculo de tributos

\- Exibição dos dados das contas



\## 🛠️ Tecnologias utilizadas



\- Java

\- IntelliJ IDEA

\- Git

\- GitHub



\## 🎯 Objetivo



Este projeto foi desenvolvido para praticar conceitos de POO em Java e aprimorar a lógica de programação através da construção de um sistema bancário.
